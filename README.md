# SIRAT (صِرَاط) — Architectural Islamic Companion

**Sirat** is an ad-free, architectural Islamic super-app built with Flutter & Native Android Instruments. Designed as a *Sadaqah Jariyah* for the global Ummah.

## Key Features (v1.0.0 Official Release)

* **First-Launch Interactive Flashcards:** Smooth 4-card onboarding deck with instant Name & City personalization.
* **Dual-Pane Salah Horizon & Exact Alarms:** Live prayer countdown, Hanafi/Shafi'i support, custom Masjid time override, and exact native Android prayer notifications (*"May Allah accept your prayers"*).
* **Noble Quran (114 Surahs) in Quran.com Script:** Authentic Uthmani/Amiri calligraphy, multi-language translations (English, Hindi, Urdu), and audio recitation by Mishary Rashid Alafasy.
* **Global 10-Book Hadith Vault:** Instant search across *Sahih al-Bukhari, Sahih Muslim, Sunan an-Nasa'i, Abu Dawud, Jami' at-Tirmidhi, Ibn Majah, Muwatta Malik, An-Nawawi's 40, Hadith Qudsi,* and *Shah Waliullah's 40 Hadith*.
* **Direct-Sync Native Android Widgets:** Dual-Pane Live Chronometer Prayer Widget & Daily Quran Verse Widget with customizable themes and Arabic font sizes.
* **Spiritual Streak & Analytics:** Radial consistency gauge, 7-day bar chart, prayer-by-prayer discipline meters, and 30-day matrix.
* **Owner Admin Control Panel:** Built-in remote configuration (PIN: `7860`) for live banners, broadcast popups, and developer branding.

## Automated Cloud Build
Every push to `main` automatically compiles the release Android APK via **GitHub Actions** (`Sirat-v1.0.0-Official-APK`).
